# Contributing

Thanks for helping! 

1. Fork and create a branch.
2. `npm install && npm run dev`.
3. Make your change; run `npm run build` to confirm it passes.
4. Open a pull request describing what and why.

Docs improvements, bug fixes, and theme/config enhancements are all welcome. Keep the project small and template-friendly. See [AGENTS.md](AGENTS.md) for conventions.
