# Getting Started

## 1. Get the project

Click **Use this template** on GitHub (or fork the repo), then clone it:

```bash
git clone https://github.com/<you>/<your-repo>.git
cd <your-repo>
npm install
```

## 2. Preview live

```bash
npm run dev
```

Open the printed URL. Edits to any `.md` file in `docs/` appear instantly.

## 3. Write

Add a file such as `docs/my-page.md`. It shows up in the sidebar automatically. See [Writing Docs](/docs/writing-docs).

## 4. Publish

Push to `main`. See [Deploying](/docs/deploying) for the one-time GitHub Pages setting.
